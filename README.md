# Responsive Profile Card

This is a responsive profile card that I built using only HTML and CSS.

It is my **first ever webpage built completely with HTML and CSS**, and it marks the beginning of my web development journey. Through this project, I practiced creating layouts, working with Flexbox, designing a clean UI, adding icons and links, and making the page responsive for different screen sizes.

## Features
- Responsive design
- Clean and modern UI
- Social media links
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3

## About This Project
This project was built as a learning project to improve my frontend development skills. I plan to keep building more projects and update this repository as I continue learning.
